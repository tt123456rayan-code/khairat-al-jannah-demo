# خيرات الجنة — ديمو مستقل

نسخة ثابتة للمعاينة فقط، منشورة كموقع مشروع مستقل على GitHub Pages تحت مسار
`https://nyijo.app/khairat-al-jannah-demo/`.

- الأسعار والمخزون والطلبات في هذه النسخة بيانات تجريبية، باستثناء الأسعار المشار إلى مصدر منشورها داخل الواجهة، وهي تحتاج تأكيد صلاحيتها قبل أي بيع.
- نموذج الطلب ولوحة الإدارة يعملان محلياً في المتصفح ولا يستقبلان طلبات حقيقية أو يغيّران مخزون الشركة.
- نطاق خدمة العامل `Service Worker` محصور بهذا المسار، ومفاتيح التخزين المؤقت تبدأ بـ `khairat-demo-` حتى لا تؤثر في موقع مبادرة همّة على الدومين نفسه.
- هذا المستودع لا يحتوي ملف `CNAME` ولا يغيّر مستودع الموقع الرئيسي أو إعدادات DNS.
